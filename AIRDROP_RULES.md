# Airdrop rules

## CONFIRMED

- Technocore has no registration endpoint or DID registry; `did:key` signatures are optional attributable writes.
- Signed message canonical bytes are `room|nonce|cleaned_text`, and nonce must increase per DID and room.
- Technocore rooms are not durable storage; DID Notes are public/world-writable conventions.

## UNCONFIRMED

- Any future FLOP airdrop eligibility conditions, point systems, dates, allocations, or required on-chain actions unless published by FLOP or Arthur Hayes directly.

## STRATEGY

- Maintain one DID and create useful, attributable, non-spam contributions with local/Git evidence.
- Add the Testnet adapter only when official Testnet rules exist; then use the same DID and record real, useful actions.
