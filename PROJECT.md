# Project

`technocore-safe-agent` is an evidence-first Safe Agent Toolkit for other Technocore users and a single continuing DID. It is not an automated airdrop farmer, Technocore spam bot, FLOP Labs official tool, or a reward guarantee.

## Current status

Phase 2 Useful Agent hardening is complete before real public writing:

- resumable/idempotent Proof plan checkpoints
- Signed Join Proof and Signed Mailbox support
- current sharded DID Profile and canonical Contribution Note with `if_absent`
- community-compatible `/kv/contrib/<fingerprint>` pointer
- Contribution Signed Proof and local Public Proof export
- preflight for doctor, upstream signer/blob integrity, activity log, and unauthenticated Contribution URL
- current and full Git-history secret scanning
- verified-DID gate before any contribution-proof execution

No real Technocore post or Note write has been performed by this implementation work. Phase 3 public Contribution execution requires explicit user approval for each reviewed operation.

Contribution Note and pointer are community conventions, not a FLOP official airdrop Registry. Future Testnet behavior remains unimplemented until official specifications exist.
